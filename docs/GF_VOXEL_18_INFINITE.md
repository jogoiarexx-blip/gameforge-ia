# GF-VOXEL-18 — Mundo expansível experimental
Núcleo separado do runtime finito. Geração por coordenadas globais usando paisagem existente, árvores determinísticas e cache LRU de 4096 colunas. Limite explícito de coordenadas ±1.048.576 blocos (2.097.152 de largura); não é literalmente infinito, evita perda de precisão grosseira em WebGL, mas futura origem flutuante é necessária para câmera distante. Sem pré-alocação do mapa. Janela antecipada por chunk, halo de 8 para luz e malhas, até 9 regiões necessárias; cache padrão 16. API prepare/canEnter/get/edit/snapshot/flush. Descarta regiões distantes após gravar alterações, falha impede travessia; IndexedDB via adapter do GF-VOXEL-15. Árvores naturais são blocos regenerados determinísticamente; alterações persistem como edições. Não há crescimento de árvores nem estado de entidades/inventário. Snapshots síncronos: mover para worker ou geração incremental antes de ativar no jogo. Plano legado valida e separa edições criativas sem escrever; não migra automaticamente, rejeita registros com árvores/recursos. Use namespace distinto para o novo modo. 
Validação: testes isolados com funções reais de terreno e streaming confirmaram travessia, snapshots, recuperação de edições após nova instância e limite do cache. Quatro testes Node adicionados. Runtime jogável, IndexedDB real, FPS e migração completa pendentes.
