10 / ROTEIRO DO GDDCrie o jogo por etapas

Organiza todo o Markdown em tarefas rastreáveis, inclusive GDDs de 300 KB. As tarefas começam pendentes. Gerar código não comprova que o requisito está pronto.

Analise o documento para gerar as tarefas.
Selecione uma tarefa para ver os requisitos e preparar um comando específico.
